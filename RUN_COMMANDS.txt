REDINGTON PLAYWRIGHT AUTOMATION - TERMINAL RUN COMMANDS
======================================================

Save this file in:
T:\redington-playwright\RUN_COMMANDS.txt

Recommended project structure:

redington-playwright\
|-- pages\
|-- tests\
|-- fixtures\
|-- utils\
|-- test-data\
|-- .env
|-- package.json
|-- playwright.config.js
`-- RUN_COMMANDS.txt


1. OPEN THE PROJECT
===================

PowerShell:

T:
cd T:\redington-playwright

Command Prompt:

cd /d T:\redington-playwright

Open the project in VS Code:

code .


2. INSTALL THE PROJECT
======================

npm install
npx playwright install chromium

Install all supported Playwright browsers:

npx playwright install

Verify the Playwright version:

npx playwright --version


3. LIST AVAILABLE TESTS
=======================

npx playwright test --list


4. RUN ALL TESTS
================

npx playwright test

Run sequentially using one worker:

npx playwright test --workers=1

Run all tests in a visible browser:

npx playwright test --headed --workers=1


5. LOGIN TESTS
==============

npm run test:login

Direct command:

npx playwright test tests/login.positive.spec.js

Headed mode:

npx playwright test tests/login.positive.spec.js --headed --workers=1

Debug mode:

npx playwright test tests/login.positive.spec.js --debug --workers=1

UI mode:

npx playwright test tests/login.positive.spec.js --ui

11. RUN ALL REDINGTON SPEC FILES TOGETHER
=========================================

PowerShell single-line command:

npx playwright test tests/login.positive.spec.js tests/brandCreation.positive.spec.js tests/brandProfile.positive.spec.js tests/brandProduct.positive.spec.js tests/campaigns.positive.spec.js --workers=1

PowerShell multiline command:

npx playwright test `
  tests/login.positive.spec.js `
  tests/brandCreation.positive.spec.js `
  tests/brandProfile.positive.spec.js `
  tests/brandProduct.positive.spec.js `
  tests/campaigns.positive.spec.js `
  --workers=1

13. PLAYWRIGHT UI MODE
======================

npx playwright test --ui


14. DEBUG MODE
==============

npx playwright test --debug --workers=1


15. RE-RUN ONLY FAILED TESTS
============================

npx playwright test --last-failed

Headed mode:

npx playwright test --last-failed --headed --workers=1

Debug mode:

npx playwright test --last-failed --debug --workers=1


16. HTML REPORT
===============

Run tests with the HTML reporter:

npx playwright test --reporter=html

Open the latest report:

npx playwright show-report

Open the default report folder:

npx playwright show-report playwright-report


17. TRACE VIEWER
================

General command:

npx playwright show-trace "test-results\FAILED-TEST-FOLDER\trace.zip"

Example:

npx playwright show-trace "test-results\campaigns.positive-Redingt-6ad25--channels-without-launching-chromium\trace.zip"


18. OPEN RESULT FOLDERS
=======================

explorer .\test-results
explorer .\playwright-report


19. RUN ON A PARTICULAR BROWSER
===============================

Chromium:

npx playwright test --project=chromium

Firefox:

npx playwright test --project=firefox

WebKit:

npx playwright test --project=webkit

Install all browsers first when required:

npx playwright install chromium firefox webkit


20. VERIFY THE ENVIRONMENT FILE
===============================

PowerShell:

Test-Path .\.env

Display only environment-variable names without exposing values:

Get-Content .\.env | ForEach-Object { if ($_ -match '^\s*([^#=]+)=') { $matches[1].Trim() } }

Do not print the complete .env file during a demonstration because it contains credentials.

Get-ChildItem .\test-data

IMPORTANT EXECUTION NOTES
=========================

1. Always run commands from T:\redington-playwright.
2. Use --workers=1 for state-dependent and demonstration executions.
3. Use --headed when the browser must be visible.
4. Use --debug or --ui when diagnosing a failure.
5. Do not click Launch Campaign during QA automation unless explicitly authorized.
6. Verify the required upload files before Brand Creation execution.
7. Open the HTML report and trace when a test fails.
